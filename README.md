# Five Nights at Freddo's

**Инди-хоррор пародия на Five Nights at Freddy's**
Разработано на Unity 6 (URP)

---

## КАК ОТКРЫТЬ В UNITY

1. Открой **Unity Hub**
2. Нажми **Add** → **Add project from disk**
3. Выбери папку `FiveNightsAtFreddos`
4. Открой в **Unity 6** (6000.x.x)
   - Если появится предупреждение о версии → нажми **Continue**
5. В Unity нажми ▶ **Play** — игра запустится!

---

## УПРАВЛЕНИЕ

| Кнопка | Действие |
|--------|----------|
| Мышь | Смотреть по сторонам |
| ЛКМ (зажать) | Включить фонарик |
| ПКМ | Открыть камеры слежения |
| ESC (3 сек) | Выйти в главное меню |
| W→I→N→D→Y | Пасхалка windy31 |

## НОЧИ

| Ночь | Описание |
|------|----------|
| 1 | Обучение — только Фреддо |
| 2 | Появляется Бонита |
| 3 | Выходит Чика-Лока |
| 4 | Активируется Фокси-Рекс |
| 5 | Появляется GLITCH |
| 6★ | Бонусная — все усилены |
| 7★★ | Кастомная ночь — выставь уровни сам |

---

## АНИМАТРОНИКИ

- **Фреддо** (aiNum=0) — вожак, медленный, но слышит всё
- **Бонита** (aiNum=1) — быстрая, нападает справа
- **Чика-Лока** (aiNum=2) — атакует из темноты
- **Фокси-Рекс** (aiNum=3) — рывок из левого коридора
- **GLITCH** (aiNum=4) — телепортируется, исчезает при прямом взгляде

## ИСТОРИЯ
